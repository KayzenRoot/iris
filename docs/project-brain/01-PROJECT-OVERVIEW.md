# Hive IRIS - Project Overview

IRIS means **Intelligent Rendering & Immersive Synthesis**.

IRIS is intended to become the visual and multimodal production engine of the Hive ecosystem: high-quality 2D, 2.5D and 3D assets, animation, VFX, audio and web/game visual production, including future Blender/Maya/ComfyUI-class integrations.

Target roles: HIVE = context/retrieval/memory; CORE = cognition/orchestration when later admitted; IRIS = visual/multimodal creation and quality pipeline.

Current phase is bootstrap only. Product architecture, model/tool selections and runtime contracts require dedicated planning.
