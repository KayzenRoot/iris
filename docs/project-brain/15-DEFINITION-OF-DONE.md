# IRIS Definition of Done

## Bootstrap increment DoD
Source Pack consistent; exact Git source and optional pinned GEF release; standalone repository governance validation and tests pass without external context/memory services; exact-head CI passes; Evidence Bundle bound to base/head; independent audit APPROVED with no HIGH/CRITICAL; checkpoint promoted only after the actual protected merge and independently green exact-main evidence.

## IRIS V1 release DoD
Not yet frozen. Discovery must refine it before implementation can claim V1 completion. Minimum outcome: functional + tested + documented + deployed + validated, with measurable visual/motion/performance gates.
