# IRIS Security Governance

Never commit keys/secrets/private paths. Treat prompts, models/assets, external files, DCC scenes and future plugins/MCP inputs as untrusted until validated. No external memory server, database, mandatory MCP connector or stale local index participates in the IRIS authority chain. Git retains truth. Future DCC/model execution requires sandboxing/path controls/threat analysis. HIGH/CRITICAL security defects block promotion.
